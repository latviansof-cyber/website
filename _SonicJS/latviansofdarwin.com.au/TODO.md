1. SQUARE donation links
   Implemented on the Donate page: https://latviansofdarwin.org.au/en/donate
   Configure the five fixed Square links in Admin → Content → Site Settings under “Square Quick Donate”.

2. Membership form
   Implemented on the Membership page: https://latviansofdarwin.org.au/en/membership
   Configure the destination in Admin → Content → Site Settings → “Membership Form URL”.

3. Donation widget for the any amount
   Flexible donation destination is implemented on the Donate page: https://latviansofdarwin.org.au/en/donate
   Configure it in Admin → Content → Site Settings → “Square Flexible Donation Widget URL”.
   Note: the page still displays the local amount input, but the Square widget URL is the external flexible-payment destination.

4. Trusted partners list, editable
   Implemented on the homepage: https://latviansofdarwin.org.au/en#trusted-partners
   Edit each partner in Admin → Content → Trusted Partners. Each entry has Title, Description, Logo, URL, and Sort Order fields.

5. Footer to make completely editable
   Implemented across all public pages through the shared footer, for example: https://latviansofdarwin.org.au/en
   Edit footer sections in Admin → Content → Footer.
